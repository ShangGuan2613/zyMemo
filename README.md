# zyMemo · 与 TA 的回忆

温馨可爱的可批注微信回忆册（U 盘便携版）

## 当前进度

**✅ PR 1 前端骨架已完成并可运行**

- 使用 Tauri 2 + Svelte 5（轻量、易维护）
- 三段式布局已实现：
  - 左侧：文字聊天 / 媒体库 Tab + 目录
  - 中间：聊天气泡（粉/薄荷）或照片瀑布流
  - 右侧：批注面板（8 个固定标签 + 输入）
- 完整 Mock 数据 + 点击交互
- 颜色系统已按设计：奶油底 + 樱花粉 + 薄荷绿 + 暖巧克力文字 + 大圆角

## 快速启动（macOS / Windows 开发机均可）

```bash
npm install
npm run tauri:dev
```

首次运行会编译 Rust 侧（需要 Rust 已安装），之后热更新很快。

窗口背景为设计规定的奶油色 `#f8f1eb`，直接就能感受到温暖的感觉。
